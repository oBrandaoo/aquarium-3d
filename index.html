Guia da expedição

Siga as luzes.

Explore a redoma, fotografe cinco espécies marinhas do Brasil e visite os três habitats. O diário guarda suas descobertas neste navegador.

Computador: W A S D para nadar, mouse para olhar, Espaço e Ctrl para mudar de altura, E para o sonar, L para a lanterna, G para o diário, P para fotografar, R para conhecer um habitat próximo e M para o som. Mire no peixe e clique na água para abrir uma ficha já descoberta.

Celular: use o controle à esquerda para nadar, arraste a metade direita para olhar. Toque no ícone de câmera para fotografar e em “Explorar habitat” perto de um marco luminoso.

O mergulho não pôde começar.

Este navegador precisa ter WebGL ativado para mostrar o aquário. Tente abrir a página em uma versão recente do Chrome, Edge ou Firefox.
