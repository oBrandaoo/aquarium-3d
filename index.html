Guia da expedição

Siga as luzes.

Encontre cinco espécies marinhas do Brasil. Ao chegar perto de um peixe, ele entra no diário; toque no nome para ler sua ficha.

Computador: W A S D para nadar, mouse para olhar, Espaço para subir, Ctrl para descer, E para emitir um pulso e F para rever a última ficha. Clique na água para capturar o mouse.

Celular: use o controle à esquerda para nadar, arraste a metade direita da tela para olhar e use as setas para mudar de altura.

O mergulho não pôde começar.

Este navegador precisa ter WebGL ativado para mostrar o aquário. Tente abrir a página em uma versão recente do Chrome, Edge ou Firefox.
