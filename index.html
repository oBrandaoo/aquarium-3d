Guia da expedição

Siga as luzes.

Explore a redoma e encontre cinco espécies marinhas do Brasil. Depois, abra qualquer ficha pelo diário ou selecione o peixe na água.

Computador: W A S D para nadar, mouse para olhar, Espaço e Ctrl para mudar de altura, E para usar o sonar, L para ligar a lanterna e G para abrir o diário. Clique na água para capturar o mouse.

Celular: use o controle à esquerda para nadar, arraste a metade direita para olhar e toque nos botões para mudar de altura, acender a lanterna e emitir um pulso.

O mergulho não pôde começar.

Este navegador precisa ter WebGL ativado para mostrar o aquário. Tente abrir a página em uma versão recente do Chrome, Edge ou Firefox.
